# PowerShell Commands — IT Tech Reference

A working reference of PowerShell commands worth knowing for day-to-day
IT support/sysadmin work, built up while working on the AD/DNS/DHCP
migration and the M365 mailbox migration projects. Practical, real
commands with a one-line explanation each — not exhaustive documentation,
a field reference for the commands that actually get used.

## Categories

- [[Active Directory]] — domain users, computers, groups, OUs
- [[Local Users and Groups]] — local machine accounts, not domain accounts
- [[DNS]] — zones, records, cache
- [[DHCP]] — scopes, leases, reservations
- [[File Shares and Permissions]] — SMB shares, NTFS ACLs
- [[Networking Diagnostics]] — connectivity, IP config, DNS resolution
- [[Firewall Rules]] — viewing/creating/removing rules, profiles, logging
- [[System and Services]] — services, processes, features, updates, disks
- [[Microsoft 365 and Exchange Online]] — connecting, mailboxes, licensing

## How to apply

Add to these as new useful commands come up in real work rather than
trying to be complete upfront — a living reference beats a one-off dump.
